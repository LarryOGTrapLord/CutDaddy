// cut bench — cutting + masking + retouching

replicable method — same 6 steps for any asset
1. SOURCE: upload anything, or use the sample card (green = magic-cut practice). 2. CANVAS: each canvas is a separate project (dropdown to switch, ＋ new, ⧉ duplicate, ✖ twice deletes, name it inline). Everything below persists per canvas. 3. CUT: drag ▦ rect for a new box (tap a box to select/move it, handles reshape) — boxes stack and each has its own color. Lasso around subjects — every close makes a NEW poly. ◎ subject grabs the biggest blob in one touch, ◉ blobs grabs each piece. Path ⌁ → selection adds its curve as a poly. ＋ keeps an area, － punches out. ◐/◑ flips: keep inside vs keep outside. 4. PATHS (⌁ path): ADD taps/drags anchors, EDIT moves them (big handles). Drag empty space to move the whole path. ↩ undo restores deletes/moves. ∿/┐ toggles curved (anchors bend it) vs straight; → selection copies the curve; ✎ stroke paints the curve into the mask; ⍈ snap pulls every anchor to detected edges. Nudge pad / arrow keys: 1px per tap (shift 5px on keyboard, double-tap 5px on touch). Snap row: grid overlay + snap-to-grid, magnetic pulls to detected edges (edges toggle previews them). 5. MASK: keep/cut brushes paint the alpha. Red = cut away. Every stroke replays — nothing is destructive. 6. MAGIC: click a background color to key it out. Tolerance persists; paint back details with the keep brush. 7. LAYERS: ⧉ copy→layer lifts the selection onto a new layer (base intact); ✂ cut→layer also punches the shape out of the base. Per layer: 👁, opacity, blend, x/y offset, ↑/↓ order, ✖, ↩ undo. Export PNG includes all visible layers. 8. GRID NODES + EXPORT: feather softens the edge, contract shrinks/grows it. Send cut to grid as an element / asset / piece / object — each becomes a node (size · aspect · kept% · scale with lockable proportions, tap the kind tag to re-tag, filter by kind). Edit reloads a node for further refinement. VIEW switches the result between composite / mask / base; LAYOUT reflows the panels (side / stack / edit / result); ⧉ pop opens the result in its own window. Export transparent PNG, keep as note, or save the recipe JSON.

// rig lab — act 1: 2d cutout character

replicable method — same 5 steps for any character image
1. SOURCE: front-facing character, arms slightly out, feet apart. Transparent PNG reassembles cleanest; any image works — cut one in the cut bench first for best results. 2. REGIONS: the 15 canonical sections are overlaid. Click a part, drag its box to fit (corner grip resizes, red dot drags the pivot). 3. DICE: each region is cut to its own rigid sprite. Pieces never deform — only rotate. 4. PIVOTS: put each red dot on its joint (neck, waist, shoulders, elbows, wrists, hips, knees, ankles). 5. LAYERS + POSE: ↑/↓ sets draw order back→front; sliders drive the FK bones. Presets + dance to test. Export JSON = the whole recipe.
